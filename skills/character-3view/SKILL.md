# 人物视频参考设定集（Grok）

给 Imagine 出静帧，再交给 grok-video。不拆小说、不跑脚本。

每轮默认交四样：
1. 身份锁定
2. 文字人设卡（性格、音色、口吻、动作习惯、视频禁区）
3. 可粘贴英文布局提示词
4. 密信息设定图。没说只要三视图就出完整集。

图上的中文容易乱码，所以人设卡必须写在回复里。图上只用短英文标签和一小块 NOTES。

## 文字人设卡（每轮必写）

用户没给性格音色时，按参考图气质推断，并标明「推断，可改」。

```
姓名/称呼：
身份锁定：（头身比、发型、五官、服装剪影、常驻道具、风格）
性格：3 至 6 个词 + 一句处事方式
音色：音高、气息、语速、共鸣（胸/头）
口吻：口头禅、称呼习惯、说话时嘴型习惯
动作习惯：站姿、手往哪放、走路节奏
视频用法：身份句怎么引；适合的镜头；不要做的动作
```

视频身份句固定：

```
Preserve the reference sheet subject's facial identity, hairstyle, outfit silhouette and colors. Do not change the face.
```

## 密信息板版面（默认出图）

一张横构图，信息要密，不要只有四视图：

```
左上 半身基准
上排 头模：正 / 3/4 / 侧 / 后脑
中排 全身四视图 + 淡身高线，A-pose，头到脚
左下 配色条
下排 零件特写：发型或夹、眼、帽或嘴、配饰、材质、衣缝、鞋或脚、其他标志物
右侧或底部一小块英文 NOTES：personality / voice 各一行，短词，不要长中文段落
```

一次一张。表情条、换装、拆解衣另出，避免压扁人物。

## 出图约定

- 横图。有参考用改图并写版面。
- 布局英文。回复里的人设用中文。
- 图上标签只用英文短词。
- 不要原图场景、水印、海报。

## 质检

脸是否同一人；脚是否完整；有无带入沙发摊位食物；侧视是否 90 度；衣服是否一致；回复里是否已写人设卡。

## 不要做的

- 不要只出一行三视图交差
- 不要把长中文段落塞进图里当唯一说明
- 不要 Node / Codex / 别人仓库 CLI
- 未成年人性化内容拒绝
