# 文件规划

受 Manus 式 planning-with-files 启发。

## 目标

多步骤任务把计划和发现写在磁盘上，长跑、上下文重置后目标不丢；聊天保持简短。

## 默认位置

优先用户 PC：`E:\ai-local-memory\scratch\plans\`；否则我这边：`/workspace/scratch/plans/`。

任务 slug `{slug}`：
- `task_plan.md` — 目标、步骤、状态
- `findings.md` — 关键发现与证据
- `progress.md` — 进度时间线

## 步骤

1. 开任务时建三个文件并写清目标
2. 每完成一步更新 plan 勾选与 progress
3. 重要结论写入 findings，聊天只回摘要
4. 结束时确认三份文件一致再宣称完成
