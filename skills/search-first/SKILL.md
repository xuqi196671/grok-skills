# 搜索优先 — 写代码前先找现成方案

改编自 ECC `skills/search-first`。优先复用，少从零造。

## 何时用

- 新功能很可能已有现成方案
- 要加依赖或做集成
- 用户说「加 X」而你正要写代码
- 新建工具函数/抽象之前

跳过：一行级小修、纯重构、只改文档。

## 步骤

1. 用关键词搜 GitHub、包仓库、网页
2. 记下 1–3 个可复用仓库/库
3. 裁决：采用 / 扩展 / 组合 / 自建
4. 再写代码；聊天里点明依据
