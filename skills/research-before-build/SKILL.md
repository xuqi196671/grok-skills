# 动手前先调研

配合「搜索优先」。用于「该不该做 / 用哪套方案」，不只选包名。

## 步骤

1. 用 2–3 句说清需求（做什么 / 技术栈 / 约束）
2. 按序搜：本地与 `E:\ai-local-memory` → 包仓库 → GitHub/网页 → 已装技能/MCP
3. 对比 2–3 个真实候选（维护、契合度、协议）
4. 收尾一行裁决：

`裁决：采用|扩展|组合|自建 — <名称或自研> — <带证据的理由>`
