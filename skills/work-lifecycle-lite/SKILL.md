# 工作闭环精简版

从各类 lifecycle 技能包瘦身而来。用于非琐碎交付。

## 阶段

1. **规格** — 完成长什么样？约束？
2. **计划** — 小步拆解（长任务用「文件规划」）
3. **构建** — 一次只切一片
4. **验证** — 走「完成前先验证」
5. **交付** — 交出产物/路径；记下后续

## 规则

- 串起：搜索优先 → 本地缓存 → 文件规划 → 完成前验证
- 不可逆操作（发消息、花钱、删东西）先问用户
- 聊天短，细节落盘
