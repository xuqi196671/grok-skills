# 企业微信套件（wecom-operations）

来源：豆包技能市场「企业微信」长截图（经分段识读整理）。
副标题场景：通过企业微信机器人发送消息、图片和文件；正文为 `wecom-cli` / `@wecom/cli` 全能套件。

```yaml
name: wecom-operations
description: 企业微信 CLI (wecom-cli / @wecom/cli) 操作套件。用于安装或升级 CLI、初始化环境、登录和身份认证、扫码授权，以及通过命令行操作企业微信文档、智能表格等 CLI 已支持的功能。当用户直接在技能栏引用 /wecom-operations，提到 wecom-cli、@wecom/cli 或「企业微信 CLI」，或明确要求通过命令行完成企业微信的登录、授权、初始化及相关操作时使用。
```

企业微信 CLI（`wecom-cli`）全能套件，通过命令行与企业微信交互。下方「业务域概览」是路由表：判断用户意图属于哪个业务域，然后读取该域对应的 reference 文件，再按其中的参数规范构造命令。**严禁凭路由表描述或自身记忆猜测拼参数。**

发消息、删改、改权限等不可逆操作：先问用户再执行（叠「可逆直做」）。密钥不进技能正文。

## ⚠️ 前置检查 — 使用任何命令前必须执行

### Step 1：检查 CLI 是否安装且版本 ≥ 1.1.0

```bash
wecom-cli --version
```

命令不存在、报错，或版本 &lt; 1.1.0 时安装：

```bash
npm install -g @wecom/cli
```

装完再跑 `--version`；仍失败或仍低于 1.1.0 则停止业务操作，并把错误告知用户。

### Step 2：检查凭证是否配置

```bash
wecom-cli auth show --status
```

- `authorized` → 已配置，可继续
- `unauthorized` → 未配置，执行 Step 3
- 报错或其它输出 → 停止，告知用户，不要猜测授权状态

### Step 3：配置凭证（仅未授权时）

```bash
wecom-cli auth init --noninteractive
```

会输出授权链接和二维码，并阻塞等待用户扫码；成功后命令自动退出，一般只需一次。
完成后再次 `auth show --status`，仅当 `authorized` 才能继续业务命令。

## 获取个人身份

流程必须获取机器人或授权人身份（姓名等）时：

```bash
wecom-cli identity whoami
```

## 通用输出约束：ID 类字段禁止外露

对所有 `wecomcli-*` 相关操作生效，优先级高于各域输出格式，**不因用户主动索要而放宽**。

- **禁止**：最终回复出现 `userid` / `open_vid` / `department_id` / `chat_id` 等；凡接口返回的内部标识（含 `mail_id` / `media_id` / `file_id` / `space_id` / `folder_id` / `docid` / `content_id` / `msg_id` / `cursor` / `next_cursor` 等，以 `_id` 结尾或语义属机器标识的字段）只能内部流转。
- **必须**：思考与最终回复使用可读名称，如 `name` / `username` / `external_username` / 部门名 / 邮箱 / `subject` / `doc_name` / `chat_name` / `title` 等。
- 只有 ID 时：先读对应域 reference（人员见通讯录）换可读名；实在换不到，用自然语言描述对象，禁止退化为展示 ID。
- 多选：序号 + 可读信息，禁止用 ID 区分。
- 用户要「把 ID 给我」：说明属内部字段不便提供，改用可读信息或继续办事。
- **例外**：可读链接（文档 `doc_url`、微盘分享链接等）可给用户。

## 业务域概览（路由）

判域 → 读该域 `references/*.md`（若已安装官方 skills）→ 再下命令。
官方包：[WeComTeam/wecom-cli](https://github.com/WecomTeam/wecom-cli)（可 `npx skills add WeComTeam/wecom-cli` 获取 reference）。

### 👤 通讯录（contact）

按姓名、拼音、英文名或别名批量模糊搜索；消歧同名；解析供其它域使用。结果含姓名、英文名/别名、邮箱、职务、部门路径。
→ `references/wecomcli-contact.md`

### 📄 文档（doc）

`/doc/` 在线文档：新建、导入、读取、末尾追加、全量覆盖。仅当用户明确指定 doc，或给出 `https://doc.weixin.qq.com/doc/xxx` 时走这里。新建统一「生成 .docx → 导入」。未指定品类的「创建/写/整理成文档」默认走智能文档；搜索、改名、加成员或改权限走文档公共管理。
→ `references/wecomcli-doc.md`

### 📁 文档公共管理（doc-manage）

各文档品类共用管理入口：搜索（可命中 PPT、收集表、脑图、流程图、汇报、PDF 等）、改名、加成员/改权限、设置链接加入规则。**不负责正文读写。** 用户只给文档名时先走本域定位。
→ `references/wecomcli-doc-manage.md`

### 📊 在线表格（sheet）

`/sheet/`：新建、CSV/Excel 导入、读基础信息与区域、改指定区域、末尾追加行、增删子表。明确「在线表格」或 `https://doc.weixin.qq.com/sheet/xxx` 时走这里；`/smartsheet/` 或智能表格请求改走智能表格。搜索/改名/权限走文档公共管理。
→ `references/wecomcli-sheet.md`

### 🧮 智能表格（smartsheet）

数据/结构/展示：创建导入、读写子表字段记录视图图表、增删改结构与记录、筛选排序分组公式与图表、行列着色高亮条件格式列宽隐藏冻结等。添加/更新记录若返回 `851003` 或 `no authority`，回退域内 Webhook。用户说「表格 / Excel 表 / 企微表格」且未指定类型时**默认本域**；明确「在线表格」或 `/sheet/` 走在线表格。搜索改名权限走文档公共管理。
→ `references/wecomcli-smartsheet.md`

### 📰 智能文档（smartpage）

创建与 Markdown 导入、读页面树与正文、移动修改布局、追加或覆盖、块级编辑、附件上传、搭数据驱动页/表单/图表页。关键词「智能文档 / 智能主页 / smartpage」，或 `doc.weixin.qq.com/smartpage/...`、`page.weixin.qq.com/smartpage/...`。未指定品类的「创建/写/整理成文档」**默认本域**。已发布链接只读，需编辑态链接才能改。内部数据表记录与结构委托智能表格，页面展示层仍归本域。
→ `references/wecomcli-smartpage.md`

### 🤖 企业微信机器人（wecombot）

群聊机器人消息推送：文本、图片、文件、Markdown、图表（图表委托智能表格）。可实时推或经 Webhook 定时/触发推。用户提「让机器人发消息 / 群播报 / 提醒」时走这里。若有私聊或外部群限制，先提示完成机器人配置或授权。
→ `references/wecombot.md`

### 📅 日程（calendar）

创建/浏览/搜索/详情/更新/取消日程；多人忙闲与共同空闲；办公楼/会议室可用性与预订变更。本域负责**无在线会议链接**的安排（含纯线下）。含会议 ID/入会链接的归会议域。创建时歧义按 reference 消歧；查询歧义则两边都查并合并。暂不支持周期日程创建更新取消，以及邀请接受/拒绝。
→ `references/wecomcli-calendar.md`

### 🎥 会议（meeting）

在线会议（含会议 ID 或入会链接）的创建、列表、搜索、详情、更新、取消；读智能纪要、会议待办、全文转写，可按要求生成定制摘要。创建/更新时间须查日程忙闲；涉实体会议室则经日程域查可用性并占房。无在线链接的安排改走日程。消歧与搜索规则同日程。暂不支持周期会议与邀请管理。
→ `references/wecomcli-meeting.md`

### ✅ 待办（todo）

创建单条或批量待办（可分派参与人、设截止并请求截止提醒）、查详情与列表（按创建/截止时间、完成状态、标题/描述关键词筛选）；改标题描述参与人全量名单截止时间；完成待办；删除整条或退出他人创建的待办。关键词字面匹配。提醒时刻以后端为准；暂不支持单独改指定参与人接受/拒绝/未完成状态，也不能直接关提醒或自定义任意提前提醒时刻。
→ `references/wecomcli-todo.md`

### 💾 微盘（disk）

微盘/网盘/共享空间最近文件；按关键词、类型或创建者搜索文件（可附共享空间范围）；搜索文件夹或共享空间本身；读元信息与路径、上传、下载离线二进制、重命名支持的文件、新建文件夹。触发：「微盘 / 网盘 / 共享空间」或 `https://drive.weixin.qq.com/s?k=...`。本域管**文件级**操作；正文读写归对应文档域；各文档品类改名归文档公共管理。移动、删除、复制文件，删除/重命名文件夹，以及空间和分享权限管理暂不支持。
→ `references/wecomcli-disk.md`

### 📧 邮件（email）

发送、回复/全部回复、转发；抄送密送、本地附件与正文内嵌图片；按关键词/发件人/时间/已读/文件夹/标签/附件/星标/重要等浏览搜索；读正文附件与内嵌图片。仅当用户明确提「邮箱 / 邮件」时，本域才处理经邮件发出的日程邀约或会议预定；日程/会议实体仍归对应域。标记已读未读、删除、草稿、标签写操作、撤回及修改已发送邮件暂不支持。读附件/图片若返回媒体标识，再委托媒体文件域下载。
→ `references/wecomcli-email.md`

### 💬 消息（message）

向当前授权人，或机器人最近有往来的单聊/群聊发送 Markdown（普通文本也按 Markdown）、图片、文件、AMR 语音和视频；也可查询本次可发送的最近会话范围。给授权人发无需先查会话列表；给其他对象发时，目标必须来自本次会话列表，不能直接用通讯录结果或历史会话标识。媒体消息需先委托媒体文件域把本地文件上传为可发送素材。
→ `references/wecomcli-message.md`

### 🖼️ 媒体文件（media）

基于已有媒体标识下载到本地，或把已知本地路径上传为可供消息、微盘等复用的媒体素材。媒体标识必须来自真实接口返回或用户明确提供，不能用 URL 代替；防泄漏加密链接也不能经本域下载或解密。本域只负责文件搬运，不搜索素材，不解析识别文件内容。
→ `references/wecomcli-media.md`
