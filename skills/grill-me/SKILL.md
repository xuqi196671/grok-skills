# 拷问入口

只有用户明确说「拷问 / 追问方案 / grill me / 烤一下」时才用。日常聊天、已经在做的任务、先复述对齐的回合，不要自己开烤。

启动后：

1. 用一两句确认这次烤的是哪一件事，用户没反对再问。
2. 按 grilling 的问法进行。
3. 烤完用几条短句复述已定结论，等用户说没问题，才去做或改东西。
4. 不写额外方案文档，除非用户要。
